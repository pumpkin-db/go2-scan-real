# 2026-09-27 前沿简单兜底离线对照

脚本：`experiment_frontier_fallback.py`。测试原型没有接入任何启动器。

环境：Go2/.venv/ariadne/bin/python，PYTHONPATH含ROS noetic及SCAN devel/lib/python3/dist-packages。
执行脚本即可重复测试；没有ROS master、硬件运动或GUI依赖。

当前方案调用真实FrontierContinuity.choose；原型调用真实聚类和目标桥target_is_safe。
合成地图分辨率0.1m，净空0.4m、最小目标距离0.8m；图断开/无图是人为输入，未运行RL网络或节点图生成。
原型按距离米段优先、同段前沿数量优先，在前沿0.8m邻域选已知空闲合格点。
测试仅一个前沿块，未验证多区域排序优劣。连通性由独立四邻接自由栅格标记评估，非SCAN执行或机器狗体积可达性证明。
